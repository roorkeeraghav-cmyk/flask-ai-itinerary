AI Trip Planner 🌍✈️
Overview

AI Trip Planner is a web application built with Python (Flask), HTML, and CSS that helps users plan and keep track of their trips. It leverages Google Gemini AI to assist with trip suggestions and recommendations. Trip history is saved in a simple text file for future reference.

Features
AI-assisted trip suggestions using Google Gemini
User-friendly interface built with HTML and CSS
Trip history recorded in a local text file
Tech Stack
Backend: Python (Flask)
Frontend: HTML, CSS
AI Integration: Google Gemini API
Data Storage: Simple text file for trip history (no database)
